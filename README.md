# 点阵连线求解器（Flow Free / Numberlink）

自动识别游戏点阵关卡并求解：同色端点连线，路径不交叉、不重叠，可选填满全部格子。

## 一、快速使用（exe）

1. 打开 `dist\FlowLinkSolver.exe`（单文件，无需安装 Python）。
2. 点击 **「截图识别」**，屏幕进入半透明框选模式，按住鼠标拖拽框住游戏的点阵区域（尽量只框棋盘，避开下方按钮/文字），松开确认。
3. 软件自动识别网格规模（几×几）和同色端点对，显示在棋盘上。
4. 点击 **「求解」**，连线绘制在棋盘上；状态栏显示求解方式与耗时。
5. 「填满全部格子」勾选时要求路径覆盖每一格；若该关卡本身不要求填满，取消勾选后再求解。
6. `Esc` 取消框选；「清空」重置当前关卡。
7. 界面右下角的 **「窗口置顶」** 勾选后，本窗口始终显示在其他窗口最前，方便对照答案解谜；取消勾选即恢复普通窗口层级。
7. 也可点 **「手动创建」** 自行搭题：弹窗置顶覆盖游戏，先拖拽框出棋盘大小，再点格子按 红→黄→蓝→绿 成对放端点，确定后自动求解；勾选弹窗里的 **「盘迹模式」** 可切换为起点→走满棋盘→终点的盘迹玩法（见下节）。

> 首次启动 onefile 会解压数秒，属正常现象。
>
> 框选遮罩已通过 Win32 强制置顶覆盖全部屏幕。若游戏是**独占全屏**导致遮罩盖不上去，请先把游戏切换为窗口模式或无边框窗口模式再截图；框选过小、Esc 取消、超时（60 秒）都会在状态栏给出明确提示。

## 二、识别说明

- 自动分割发光端点（高饱和彩色 / 高亮白心），按 RGB 颜色聚类成对。
- 网格规模：先提取每个未占用格的暗圆，与亮端点一起按横向 / 纵向坐标聚类成列、成行，簇数即行列数；不再只靠稀疏端点的间距推算，避免端点不在外圈时把 6×6 误判成 5×5、放大后误判成 4×4。
- 暗圆不足时回退到端点间距 + 截图尺寸估算。
- 识别失败时状态栏会给出原因（端点过少、颜色簇不为 2、端点落出网格等），请放大或重新框选后重试。
- 若两组颜色非常接近（如两种浅蓝）可能被误并；此时需在游戏里换一关或手动核对。

## 三、手动创建关卡

点「手动创建」弹出置顶编辑窗口，分两步：

1. **选大小**：在候选网格上按住左键拖拽出一个矩形，松开确定 N×N 边长（范围 2~12）。
2. **放端点**：点击格子放端点；颜色按顺序成对出现——第 1、2 个点为红色一对，第 3、4 个为黄色一对，接着蓝、绿、橙、紫、青、粉循环。

按钮：

- **撤销**：取消最新放的点；已无点时回到第 1 步重设大小。
- **清空点**：清空所有端点，保留当前棋盘大小。
- **重新设置大小**：清空端点并回到第 1 步。
- **确定**：校验端点成对（每色恰好两个）后关闭窗口，自动求解并把连线画到主棋盘。

> 同一格不能重复放点；端点数量必须为偶数，否则确定时会提示还差一个同色端点。

## 三·补、盘迹模式（勾选「盘迹模式」）

在手动创建弹窗勾选 **「盘迹模式」** 后，题目逻辑变为：从**起点**出发，走满所有可走格后到达**终点**。弹窗主按钮随阶段在「下一步 / 确定」之间切换，棋盘支持长方形（行数、列数自由）。

阶段流程：

1. **选大小**：拖拽框出棋盘矩形（2~12 行 / 列，可长方形）。
2. **起点**：点击一个格子作为起点（绿色 S）。
3. **终点**：再点击另一个格子作为终点（蓝色 T）；起点终点不能同格。
4. **红区**：点击格子设置不可走的红色区域，再点一次取消；路线不能踩红区。红区可留空。
5. **传送门**：点击格子设置一对紫色传送门（至多两个，可留空）。传送门为**必走格**：路径踏入其中一格后**必定瞬移**到另一格，不能把传送门格当普通格子四邻进出；瞬移**双向、整局仅一次**；再点一次取消。
6. **确定**：进入求解，找出一条走满全部非红区格子、从起点到终点的路径并绘制到主棋盘。

规则与口径：

- 红区、传送门、起点、终点互不重叠；传送门两个格不能为同一格。
- 「走满整个棋盘」按遍历所有非红区可走格各一次（哈密顿路径）理解；两个传送门格都必须经过并计入访问。
- 撤销逐级回退到上一阶段；「清空点」在盘迹模式下清空红区与传送门；「重新设置大小」回到选大小并清空全部。
- 盘迹求解同样走回溯 DFS + 连通性 / 死路剪枝，解出后做合法性校验（起终点接入、相邻或传送边、不重复、不踩红区、走满可走格、传送门必走且经瞬移边成对通过）。

## 四、求解算法

- **主力：回溯 DFS（活动路径扩展）+ 强剪枝**
  - 度数 / 死路检测、连通分量含端点检查、端点可达性检查、填满校验。
  - 约束最强的颜色优先扩展，短路径优先尝试。
- **兜底：Z3 约束求解**
  - DFS 超时（3 秒）或失败后自动启用；边变量 + 度数约束 + 流连通建模，15 秒上限。
- 解出来后会再做一次合法性校验：端点接入、链相邻无重复、不重叠、（可选）填满。

## 五、源码结构

```
main.py              入口（含开发环境库路径注入）
flowlink/
  solver.py          flow：DFS 主力 + Z3 兜底 + 校验；trace：哈密顿路径 DFS + 红区/传送门 + 校验
  recognizer.py      截图识别：端点检测、网格推断、颜色聚类
  app.py             PySide6 界面：棋盘自绘、框选截图、手动创建弹窗、求解线程
test_cases.py        自测用例（可选）
```

## 六、从源码运行

依赖：Python 3.13、PySide6-Essentials、z3-solver、Pillow、numpy。

```powershell
python -m pip install z3-solver pillow numpy
python -m pip install PySide6-Essentials --target C:\pylibs
python main.py
```

> 本机若开启 Windows 长路径支持，PySide6 可直接装入默认 site-packages，无需 `--target`。

## 七、重新打包 exe

```powershell
python -m PyInstaller --noconfirm --onefile --windowed `
  --paths C:\pylibs `
  --hidden-import z3 `
  --add-binary "<z3安装目录>\z3\lib;z3\lib" `
  --name FlowLinkSolver `
  main.py
```

产物在 `dist\FlowLinkSolver.exe`。

## 八、已知限制

- 识别针对深色背景 + 发光圆点的典型 Flow Free 界面；其它皮肤/背景风格可能需要调整 `recognizer.py` 中的颜色阈值。
- 极大网格（12×12 以上）求解时间会明显上升，Z3 兜底也可能超时。
- 独占全屏（fullscreen exclusive）的游戏窗口普通置顶遮罩无法盖住，需用窗口/无边框窗口模式；多显示器时遮罩覆盖全部屏幕虚拟几何，截图坐标自动换算。
- 本工具只做离线计算，不读取游戏内存、不做任何外挂操作。
